# Naming Conventions

::left::

## [Java]{style="color:#ED8B00"}

<v-clicks at="1" depth="2">

- variables and methods: `camelCase`
- types (classes, interfaces, records, enums): `PascalCase`
  - enum values: `SCREAMING_SNAKE_CASE`
- constants: `SCREAMING_SNAKE_CASE`

</v-clicks>

::right::

## [Rust]{style="color:#D34516"}

<v-clicks at="1" depth="2">

- variables and methods: `snake_case`
- types (structs, traits, type aliases, enums): `PascalCase`
  - enum values: `PascalCase`
- constants: `SCREAMING_SNAKE_CASE`
- unused values: prefixed with `_`

</v-clicks>
